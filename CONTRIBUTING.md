# Contributing to Thalovant

Thanks for helping. This guide is the default for every public Thalovant
repository that has no `CONTRIBUTING.md` of its own. Follow the repository's
README and development instructions when they give more specific guidance.

## Before you start

- **Questions and ideas:** open a Discussion if the repository has them, or ask
  on [Discord](https://discord.gg/ZRVMARguxC).
- **Product help:** start with the
  [support guide](https://docs.thalovant.com/account/get-support/).
- **Bugs:** search the existing issues first, then open one with the version you
  run, what you did, what you expected and what happened. Remove credentials,
  tokens and personal data from logs before sharing them.
- **Vulnerabilities:** do not open a public issue. Follow the
  [security policy](https://github.com/thalovant/.github/blob/main/SECURITY.md).

## Sending a change

1. Open an issue for anything larger than a typo or a small fix, so we can agree
   on the direction before you spend time on it.
2. Fork the repository and create a branch from its documented development
   branch. If none is specified, use its default branch.
3. Keep the change focused: one concern per pull request.
4. Add or update tests where appropriate, and run the repository's documented
   checks. For documentation changes, check the rendered text and links. Explain
   any checks you could not run.
5. Open the pull request against the branch named in that repository's
   instructions, or its default branch when none is specified. Describe the
   change, why it helps and how you checked it; use the template when available.

By contributing you agree that your contribution is licensed under the
repository's license (see its `LICENSE` file). Forks of upstream projects follow
the upstream license and, where it asks, the upstream contribution process; for
changes that are not specific to Thalovant, please also send them upstream.

## Conduct

Everyone taking part follows the
[code of conduct](https://github.com/thalovant/.github/blob/main/CODE_OF_CONDUCT.md).
