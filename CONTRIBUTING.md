# Contributing to Thalovant

Thanks for helping. This guide is the default for every public Thalovant
repository that has no `CONTRIBUTING.md` of its own.

## Before you start

- **Questions and ideas:** open a Discussion if the repository has them, or ask
  on [Discord](https://discord.gg/FcAM8XCD). Product help lives at
  [docs.thalovant.com](https://docs.thalovant.com).
- **Bugs:** search the existing issues first, then open one with the version you
  run, what you did, what you expected and what happened.
- **Vulnerabilities:** do not open an issue. Follow the
  [security policy](SECURITY.md).

## Sending a change

1. Open an issue for anything larger than a typo or a small fix, so we can agree
   on the direction before you spend time on it.
2. Fork the repository and branch from `main`.
3. Keep the change focused: one concern per pull request.
4. Add or update tests, and run the repository's own test command (it is in the
   README). A change that cannot be tested should say why.
5. Open the pull request against `main` and fill in the template.

By contributing you agree that your contribution is licensed under the
repository's licence (see its `LICENSE` file). Forks of upstream projects follow
the upstream licence and, where it asks, the upstream contribution process; for
changes that are not specific to Thalovant, please also send them upstream.

## Conduct

Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
