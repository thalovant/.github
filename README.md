# thalovant/.github

Two things live here, and GitHub picks both up for every repository in the
organization:

- [`profile/README.md`](profile/README.md) is the page people see at
  [github.com/thalovant](https://github.com/thalovant).
- [`SECURITY.md`](SECURITY.md) is the security policy shown on any Thalovant
  repository that doesn't carry its own. Suspected vulnerabilities go to
  [hello@thalovant.com](mailto:hello@thalovant.com), privately.

Product documentation lives at [docs.thalovant.com](https://docs.thalovant.com),
and the product at [thalovant.com](https://thalovant.com).
