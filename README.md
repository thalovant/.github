# thalovant/.github

This repository holds the files GitHub reads on the organization's behalf:

- [`profile/README.md`](profile/README.md) is the page people see at
  [github.com/thalovant](https://github.com/thalovant).
- [`SECURITY.md`](SECURITY.md) is the default security policy, shown on any
  Thalovant repository that doesn't carry its own. Suspected vulnerabilities go
  to [hello@thalovant.com](mailto:hello@thalovant.com), privately.
- [`CONTRIBUTING.md`](CONTRIBUTING.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md),
  the pull request template and the issue forms are the defaults for every public
  Thalovant repository that doesn't have its own.

Product documentation lives at [docs.thalovant.com](https://docs.thalovant.com),
and the product at [thalovant.com](https://thalovant.com).
