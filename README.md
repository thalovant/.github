# Thalovant on GitHub

This repository contains Thalovant's public organization profile and default
community files.

| File | Purpose |
| --- | --- |
| [`profile/README.md`](profile/README.md) | The profile shown at [github.com/thalovant](https://github.com/thalovant) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to report bugs and propose changes |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Expectations for participating in Thalovant's public spaces |
| [`SECURITY.md`](SECURITY.md) | How to report suspected vulnerabilities privately |
| [Issue forms](.github/ISSUE_TEMPLATE/) | Bug reports, feature requests and help destinations |
| [Pull request template](.github/PULL_REQUEST_TEMPLATE.md) | What changed, why it helps and how it was checked |

GitHub uses these community files for public Thalovant repositories that do not
provide their own. Follow a repository's own instructions when present.

## Find Thalovant

- [Website](https://thalovant.com/) — product overview and ways to get started.
- [Documentation](https://docs.thalovant.com/) — setup, developer guides and support.
- [YouTube](https://www.youtube.com/@thalovant) — the OpenVoiceOS, HiveMind and Home Assistant video archive.
- [Discord](https://discord.gg/ZRVMARguxC) — community questions and discussion.

For a suspected vulnerability, email
[hello@thalovant.com](mailto:hello@thalovant.com) privately and follow
[`SECURITY.md`](SECURITY.md). Do not open a public issue containing sensitive details.
